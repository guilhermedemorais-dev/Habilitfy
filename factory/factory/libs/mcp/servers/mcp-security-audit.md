# MCP Security Audit

## Descricao
Servidor MCP para auditoria de dependencias npm e vulnerabilidades (npm audit).

## Configuracao (Codex)
- `command = "npx"`
- `args = ["-y", "mcp-security-audit"]`

## Quando usar
- Revisao de seguranca de dependencias (npm/pnpm/yarn).
- Auditoria antes de releases.

## Evidencia em PR
- Registrar a execucao do MCP e achados relevantes.
