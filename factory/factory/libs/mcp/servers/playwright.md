# Playwright MCP Server (QA)

## Descricao
Servidor MCP para automacao de navegador via Playwright, com snapshots de acessibilidade.

## Quando usar
- Validar fluxos end-to-end.
- Coletar snapshots estruturados para QA automatizado.

## Configuracao (Codex)
- `command = "npx"`
- `args = ["@playwright/mcp@latest"]`

## Evidencia em PR
- Registrar o uso do MCP quando houver automacao/QA.
