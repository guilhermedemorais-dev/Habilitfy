# GitHub MCP Server

## Descricao
Servidor MCP remoto para acesso ao GitHub (repositorios, issues, PRs, actions, etc.).

## Configuracao (Codex)
- URL: `https://api.githubcopilot.com/mcp/`
- Header (PAT):
  - `Authorization: Bearer <GITHUB_PAT>`

## Quando usar
- Leitura e analise de repositorios.
- Automacao de issues/PRs (quando permitido).

## Evidencia em PR
- Registrar uso do MCP quando houver automacao ou consulta.
