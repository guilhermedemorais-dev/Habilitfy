# MCP Servers

## O que sao
Servidores MCP fornecem contexto confiavel, documentacao e padroes externos.

## Para que servem
- Documentacao oficial.
- Contexto externo validado.
- Padroes e recomendacoes.

## Quando consultar
- Antes de implementar integracoes externas.
- Quando houver duvida sobre APIs ou comportamento.
- Quando o contexto interno nao for suficiente.

## Ordem de prioridade
1. Servidores aprovados internos.
2. Servidores externos aprovados.

## Evidencias em PR
- Link ou referencia ao servidor consultado.
- Resumo curto do que foi utilizado.
