# Quickstart (10 minutos)

## Passo a passo
1) Crie o arquivo do projeto:
   - Crie a pasta `factory/docs/projects/<NOME_PROJETO>/`.
   - Copie `factory/docs/templates/docs.template.md` para `factory/docs/projects/<NOME_PROJETO>/docs.md`.
2) Preencha visao, escopo, requisitos, regras e dados.
3) Defina stack, design system e MCP:
   - `factory/docs/templates/stack.template.md`
   - `factory/docs/templates/design-system.template.md`
   - `factory/docs/templates/mcp.template.md`
4) Gere o prompt de distribuicao:
   - Use `factory/docs/templates/distribution-prompt.template.md`.
5) Gere o prompt de build:
   - Use `factory/docs/templates/build-prompt.template.md`.

## Se travar
- Registre gaps em `factory/context/core/gaps.md`.
- Pare ate a decisao ser tomada.
