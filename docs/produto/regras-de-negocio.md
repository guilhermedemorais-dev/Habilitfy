# Regras de Negócio – Estrutura HabilitFy

## 1. Acesso e Papéis
- Definição clara de roles: **Aluno**, **Instrutor**, **Admin**
- Visibilidade e permissões distintas para cada papel
- Restrição de acesso por módulo/tela conforme role

---

## 2. Instrutores
- Aprovação manual/admin antes de aparecer para alunos
- Exibição só para instrutores com KYC/documentação aprovada
- Cada instrutor define preço/hora, pode cadastrar múltiplos veículos
- Admin pode suspender, editar ou banir instrutor

---

## 3. Booking e Pagamento
- Aula (booking) só confirmada após status **Pago**
- Split automático da comissão (percentual/fixo) para a plataforma
- Políticas de cancelamento, reembolso e re-agendamento bem definidas
- Pagamento via gateway integrado (Pix/cartão), com logs de todas as transações

---

## 4. Avaliações
- Só é possível avaliar instrutor após aula realizada (check-out confirmado)
- Rating calculado por média ponderada (nota + número de avaliações)
- Admin pode auditar/editar avaliações suspeitas

---

## 5. LGPD e Dados Pessoais
- Coleta mínima de dados necessários (cadastro, pagamentos, KYC)
- Retenção e exclusão conforme políticas LGPD
- Consentimento explícito em todos os cadastros

---

**Obs:**  
Esse bloco serve como índice/guia das regras de negócio detalhadas do HabilitFy.  
Para cada módulo (cadastro, booking, pagamento, etc.), as regras específicas devem ser detalhadas nos PRDs correspondentes.

# Regras de Negócio – Estrutura HabilitFy

## 1. Acesso e Papéis
- Definição clara de roles: **Aluno**, **Instrutor**, **Admin**
- Visibilidade e permissões distintas para cada papel
- Restrição de acesso por módulo/tela conforme role

---

## 2. Instrutores
- Aprovação manual/admin antes de aparecer para alunos
- Exibição só para instrutores com KYC/documentação aprovada
- Cada instrutor define preço/hora, pode cadastrar múltiplos veículos
- Admin pode suspender, editar ou banir instrutor

---

## 3. Booking e Pagamento
- Aula (booking) só confirmada após status **Pago**
- Split automático da comissão (percentual/fixo) para a plataforma
- Políticas de cancelamento, reembolso e re-agendamento bem definidas
- Pagamento via gateway integrado (Pix/cartão), com logs de todas as transações

---

## 4. Avaliações
- Só é possível avaliar instrutor após aula realizada (check-out confirmado)
- Rating calculado por média ponderada (nota + número de avaliações)
- Admin pode auditar/editar avaliações suspeitas

---

## 5. LGPD e Dados Pessoais
- Coleta mínima de dados necessários (cadastro, pagamentos, KYC)
- Retenção e exclusão conforme políticas LGPD
- Consentimento explícito em todos os cadastros
