Crie um projeto completo em Next.js 15 com React e Tailwind CSS, replicando exatamente a interface do app DRIVEx Instructor (um Uber para aulas de direção nos EUA), mas adaptado para o Brasil com nome 'HabilitFy' – um marketplace on-demand para agendar aulas práticas de direção com instrutores autônomos credenciados pelo Detran. Use as cores da logo: verde (#228B22) para botões principais e accents, amarelo (#FFD700) para ícones e highlights (como estrelas de rating), azul escuro (#00008B) para textos e títulos, fundos em branco ou cinza claro (#F5F5F5). Todo o texto deve estar em português brasileiro, com referências culturais como 'CNH fácil', 'instrutores próximos no Brasil', icons de carros com placa BR, e integrações como WhatsApp para contato e Pix para pagamento.
Estrutura o app como PWA mobile-first (responsivo para web e mobile), com App Router. Inclua autenticação simples via Supabase Auth (login com Google ou WhatsApp). Use Leaflet.js para mapas com OpenStreetMap (geolocalização realtime de instrutores). Integre Mercado Pago para checkout (Pix default). Gere components reutilizáveis como Button (verde rounded), Card (com sombra suave), e Icon (amarelo para steering wheel).
Telas exatas (copiando o DRIVEx, mas brasileiro):

Home / Landing Page (/): Hero com logo 'HabilitFy' em azul/verde, slogan 'Aulas de direção on-demand no Brasil – encontre instrutor perto de você!'. Campo de busca por CEP ou localização (botão verde 'Permitir GPS'). Seção de promoções: 'Primeira aula por R$69 – CNH mais fácil!'. Botão gigante verde 'Ver instrutores próximos'. Fundo com gradiente sutil verde-amarelo.
Mapa de Instrutores (/instrutores): Mapa full-screen com Leaflet, pins amarelos de instrutores (ícone de volante). Filtros laterais: preço/hora, automático/manual, distância (km), rating (estrelas amarelas). Clique no pin abre card flutuante com foto, nome, preço, reviews e botão verde 'Agendar agora'. Realtime: pins atualizam com disponibilidade.
Perfil Público do Instrutor (/instrutor/[id]): Foto grande com selo verde 'Credenciado Detran'. Detalhes: preço/hora, tipo de veículo (com ícone placa BR), bairro atendido, reviews com estrelas amarelas. Calendário interativo (use react-calendar) para horários livres (verde para disponível). Botão 'Escolher horário' em verde.
Tela de Agendamento (/agendar/[id]): Resumo: instrutor + data/hora + valor total. Checkbox amarelo 'Alugar veículo do instrutor (+R$50)'. Form: Nome, CPF, WhatsApp. Botão verde 'Ir para pagamento'. Layout clean com steps (1. Escolha, 2. Confirme).
Checkout / Pagamento (/checkout): Integração Mercado Pago (lightbox para Pix/cartão). Resumo do pedido em card azul. Botão verde 'Pagar agora'.
Tela de Sucesso (/sucesso): 'Agendamento confirmado!' com ícone amarelo de check. QR Code para WhatsApp do instrutor. Detalhes: endereço encontro, placa veículo. Botão 'Adicionar no Calendário' e 'Compartilhar no Whats'.
Tela de Cancelamento (/cancelar/[id]): Form simples com motivo, botão vermelho 'Cancelar' (mas use verde pra confirmar? Não, vermelho pra alert).
Dashboard do Aluno (/dashboard/aluno): Lista de aulas próximas (cards com data, instrutor). Histórico com botão amarelo 'Avaliar'. Saldo ou promoções brasileiras como 'Indique amigo e ganhe aula grátis'.
Dashboard do Instrutor (/dashboard/instrutor): Calendário grande com horários (verde ocupado, cinza livre). Lista de aulas do dia com nomes alunos e WhatsApp. Saldo a receber com botão verde 'Sacar via Pix'. Gráfico simples de earnings (use Recharts, linhas em amarelo).
Cadastro de Instrutor (/cadastro-instrutor): Steps wizard: 1. Upload foto credencial Detran + CNH (amarelo highlight). 2. Foto veículo com faixa amarela. 3. Preço/hora, raio atendimento. 4. Dados Pix. Final: 'Aguardando aprovação' com ícone azul.
Painel Admin (/admin): Lista de instrutores pendentes (aprovar/rejeitar com botões verde/vermelho). Relatórios de agendamentos (tabela com Tailwind).

Inclua navegação: Bottom nav bar mobile com ícones (Home: casa amarela, Mapa: pin verde, Dashboard: user azul). Use autenticação: redirecione pra login se não logado. Gere código completo: pages, components, styles (Tailwind config com cores custom), e um README com como rodar (npm install, supabase setup). Foque em design moderno: rounded corners, shadows sutis, animações leves (framer-motion para transições). Adapte cultural: adicione toques como 'Bem-vindo ao Brasil da CNH fácil!' e icons de bandeira BR sutil.
